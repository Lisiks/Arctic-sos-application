@startuml

title Диаграмма последовательности создания плана реагирования

actor Управляющий_станцией
boundary Веб_интерфейс
control Веб_приложение
control ORM
control AsyncPG
database PostgreSQL


Управляющий_станцией -> Веб_интерфейс : Данные формы
activate Веб_интерфейс
Веб_интерфейс -> Веб_приложение : POST-запрос на создание плана реагирования
deactivate Веб_интерфейс

activate Веб_приложение
Веб_приложение -> Веб_приложение : Создание ORM объект плана реагирования
activate ORM
Веб_приложение --> ORM : Запрос на добавление ORM объекта плана реагирования в БД
Веб_приложение --> ORM : Запрос на изменение истории плана реагирования в БД
deactivate Веб_приложение


ORM -> ORM : Перевод запросов с ORM на SQL
ORM --> AsyncPG : SQL запрос на добавление плана реагирования
activate AsyncPG
ORM --> AsyncPG : SQL запрос на добавление записи о плане \nреагирования в историю изменения плана реагирования
deactivate ORM

AsyncPG --> PostgreSQL : SQL запрос на добавление плана реагирования
activate PostgreSQL
AsyncPG --> PostgreSQL : SQL запрос на изменение истории плана реагирования
deactivate AsyncPG


PostgreSQL -> PostgreSQL: Обработка запросов
PostgreSQL --> Веб_приложение: Результат обработки запросов
deactivate PostgreSQL

activate Веб_приложение
Веб_приложение -> Веб_приложение : Формирование HTTP ответа

Веб_приложение -> Веб_интерфейс : HTTP ответ
deactivate Веб_приложение

activate Веб_интерфейс
Веб_интерфейс -> Управляющий_станцией : Сообщение об успехе/неудаче
deactivate Веб_интерфейс

@enduml
