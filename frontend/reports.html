Формирование отчетности

Выберите тип отчета для формирования и выгрузки данных.

Количество сообщений по типам происшествий

Группировка всех поступивших сообщений по типу происшествия с подсчетом общего количества (COUNT).

Среднее время реагирования

Расчет среднего времени от поступления сигнала до прибытия на место (AVG) на основе итоговых актов и ложных срабатываний.

Доля ложных срабатываний

Процентное соотношение ложных срабатываний к общему числу операций. Формула: (Ложные / (Акты + Ложные)) * 100%.

Готовность спасательных средств

Список спасательных средств, отфильтрованных по статусу "Готов", с группировкой по типу средства.

Количество операций по сезонам

Анализ сезонной динамики: подсчет количества операций (COUNT) с группировкой по временам года.
