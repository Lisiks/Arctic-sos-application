# Приложение для регистрации и учета сигналов бедствий на арктических станциях.

## Основные сущности приложения:

* Поступившее сообщение (источник (станции, суды, экспедиции), долгота, ширина, описание происшествия, тип происшествия (перечисление), канал связи (КОСПАС‑САРСАТ, спутниковый телефон, радиосвязь), время приема, статус (принято, в работе, завершено, ложное срабатывание));
* План регулирования (ссылка на сообщение, судно, планируемое время прибытия, метеоусловия (список));
* Журнал изменений плана регулирования (ссылка на план, те поля плана, которые поменялись);
* Итоговый акт операции (ссылка на поступившее событие, кол-во спасенных, информация об оказанной помощи, информация о затраченных ресурсах, время прибытия);
* Ложные срабатывания (ссылка на поступившее событие, описание причины, описание мер регулирования, время прибытия);
* Cпасательное средство (тип (судно, буксир, катер, СВП, вертолет), ширина базирования, долгота базирования, зона досягаемости, текущий статус (готов, в рейде, на обслуживании));
* Экипаж (ФИО, должность, ссылка на средство);
* Управляющие (логин, пароль).

## Процессы:

* Поступление сообжение;
* Создание/редактирование плана регулирования;
* Поступление информации об итоговом акте операции/ложное рабатывании;
* CRUD спасательных средств/экипажа;
* отчеты - сообщения по типам происшествия / среднее время ресгирования по актам операции / ложным срабатываниям / доля ложных срабатываний / сколько спасательных средств готово (по типам) / кол -во операций в сезонах.

## Роли пользователя:

* Управляющий (CRUD спасательных средств и экипажа, создание/редактирование плана регулирования, отчеты, заполнение итоговых актов и ложных срабатываний, ввод данных о сообщении)

## Правила и ограничения:

* тип источника (станции, суды, экспедиции, воздушное судно);
* тип происшествия (пожар, отказ двигателя, столкновение судов, посадка на мель, накренение / опрокидывание/ затопление судна, падение человека за борт, разлив нефтепродуктов, потеря связи с судном, аварийная посадка, падение воздушного судна, потеря радиосвязи с судном, отказ энергоснабжения, обрушение/ повреждение конструкций, пропажа участника экспедиции, острое заболевание/ травма в полевых условиях, отказ транспорта экспедиции);
* тип канала связи (КОСПАС‑САРСАТ, спутниковый телефон, радиосвязь);
* метеоусловия (низкие температуры, сильные ветры, высокая влажность, туманы, снегопады, метели, полярная ночь, полярный день, низкое атмосферное давление, обледенение, малая облачность, повышенная облачность);
* тип спасательного средства (судно, буксир, катер, СВП, вертолет);
* текущий статус средства (готов, в рейде, на обслуживании);
* средство можно назначить для плана регулирования только в том случае, если его досягаемости хватит чтобы преодолеть расстояние между координатами его базирования и координатами происшествия;
* средство с тиром вертолет можно вызвать только в том случае, если в метеоусловиях присутстствует (сильные ветры, туманы, снегопады, метели);
* вносить данные в систему может только авторизованный пользователь;
* нельзя составлять план регулирования по несуществующему сообщению;
* нельзя редактировать несуществующий план регулирования;
* нельзя создавать записи о ложных срабатываниях и актах операции на несуществующее сообщение;
* нельзя назначать в качестве средства члена экипажа несуществующее средство;
* нельзя назначать в качестве судна для спасения несуществующее средства.
