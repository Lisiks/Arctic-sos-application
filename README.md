# Приложение для регистрации и учета сигналов бедствий на арктических станциях.

## Основные сущности приложения:

* Поступившее сообщение (источник (станции, суды, экспедиции), долгота, ширина, характер происшествия (описание), канал связи (КОСПАС‑САРСАТ, спутниковый телефон, радиосвязь), время приема, статус (принято, в работе, завершено, ложное срабатывание)) 
* План регулирования (ссылка на сообщение, судно, планируемое время прибытия, метеоусловия (список))
* Журнал изменений плана регулирования (ссылка на план, те поля плана, которые поменялись)
* Итоговый акт операции (ссылка на поступившее событие, кол-во спасенных, информация об оказанной помощи, информация о затраченных ресурсах)
* Ложные срабатывания (ссылка на поступившее событие, описание причины, описание мер регулирования)
* Cпасательное средство (тип (судно, буксир, катер, СВП, вертолет), базирование, зона досягаемости, текущий статус (готов, в рейде, на обслуживании))
* Экипаж (ФИО, должность, ссылка на средство)
